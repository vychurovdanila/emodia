Отклонения от задания (оба — нехватка высоты на 390×844, замеры в браузере):

- **`min-height: 280px` у окна заменён на `flex: 1 1 280px`.** С жёстким
  min-height стек «окно 280 + воздух 28 + плашка 129 = 437px» не влезает в
  395px между `top: 42%` и отступом 60px: плашка ввода уезжала на иконки
  (её низ 807.7px при верхе nav 780px). С flex-basis окно берёт всё
  свободное место (238px на 390×844), растёт на высоких экранах и уступает
  на низких. Если жёсткие 280px важнее — окно поднимается до `top: 37%`
  (тогда 280px влезают, но между персонажем и окном остаётся ≈20px).
- **`gap: 16px` у `.emotion-panel` убран.** Воздух между окном и плашкой
  теперь задан их собственными отступами (`margin-bottom: 14px` +
  `margin-top: 14px` = 28px вместо 44px), иначе 44px уходили из высоты окна.

Побочный фикс: `.onboarding-tip--focus` стоял на `top: 42%` — ровно там, где
теперь верх окна текста, и ложился поверх него. Подсказка подвешена над
окном: `transform: translate(-50%, calc(-100% - 10px))` (тот же ориентир
42% минус собственная высота минус 10px зазора).

Грабли проверки: собранный бандл отдаётся PWA-сервис-воркером, поэтому
повторный прогон на `vite preview` показывает старый CSS из кэша — замеры
надо снимать с dev-сервера (без SW) или с чистым профилем браузера.

## Технические решения

- `ResizeObserver` вместо `resizeTo` (надёжнее на мобильных)
- Контейнер `world` для групповой трансформации
- Инкрементальная интерполяция в ticker (без внешних tween-библиотек)
- `BlurFilter` из PixiJS v8 для depth of field
- Named export из `EmotionSpace` (не default)
- Координаты шариков (`baseX`, `baseY`) считаются в координатах `world`;
  `layoutBalls(app, balls)` — отдельная функция для init и `ResizeObserver`
- Движение трогает только `position`; масштабом шарика управляет твин фокуса
- `centerWorld(app, world)`: `world.pivot` = центр локальных bounds,
  `world.position.x` = ширина / 2 — иначе мир сжимается симметрично
  относительно центра, а не уезжает влево. Сохранить при откате
- Координаты шариков центрированы вокруг центра мира (0,0), а не
  отсчитываются от левого верхнего угла
- Шарик в фокусе вынимается из `world` на `stage` через `getGlobalPosition()`,
  чтобы блюр не размывал его самого
- `.fog-overlay` удалён: радиальный туман с центром в 50%/50% глушил шарик
  в фокусе (он теперь в верхней четверти). Глубину дают блюр + панель
