🎨 Emoza UI Reference
Общая философия
Настроение: спокойное, тёплое, «бумажное». Не кричит, не блестит. Ощущение — дневник или детская книжка, а не фитнес-приложение.

Ключевые принципы:

Много воздуха, никакой перегруженности.

Мягкие скругления, полупрозрачные подложки с blur.

Один акцент на экране — эмозик или его цвет.

Текст — тонкий, ненавязчивый, «шёпотом».

3. Главный экран
3.1. Верхний блок — убран
Решение: главный экран открывает только матрица, текст сверху больше не показываем (проверка: «Главный: нет текста сверху, только матрица»).

Удалено из кода: массив DAILY_NOTES, состояние dailyNote, useEffect обновления текста при возврате из фокуса и CSS-класс .daily-note.

Примечание: на скриншоте главная.jpg строка ещё есть («Мотивационная мысль или краткая цитата…») — референс снят до этого решения.

3.2. Матрица 3×6
Отступы от краёв: EDGE_PADDING_RATIO = 0.06 (6% от ширины и высоты)

Зазор между ячейками: CELL_GAP_RATIO = 0.01 (персонажи почти касаются)

Размер персонажа: SPRITE_SIZE_RATIO = 1.0 (спрайт = размер ячейки)

Радиус хит-ареа: radius * 1.0 (не налезают друг на друга)

Фон: #F5F0E8

Поведение: каждый эмозик переключает кадры 0↔1↔2 по MOTION_PARAMS.

3.3. Нижняя навигация — Bottom Nav
Общее:

Позиция: position: absolute; bottom: 0; left: 0; right: 0;

Высота: 64px + env(safe-area-inset-bottom)

Фон: полностью прозрачный — ни подложки, ни backdrop-filter, ни blur. Иконки лежат прямо на фоне #F5F0E8.

Border-top: убрать (не должно быть линии).

4.2. Карусель — Carousel
Композиция (idle):

text
     [prev]      [current]      [next]
     маленький   крупный        маленький
     blur 5-8    резкий         blur 5-8
     alpha 0.55  alpha 1        alpha 0.55
     scale 0.75  scale 2.2      scale 0.75
Параметры (idle, не dragging):

Параметр Current Prev / Next

scale 2.2 1.65 (= CAROUSEL_CENTER_SCALE × 0.75)

alpha 1.0 0.55

blur 0 6

Y-сдвиг 0 0 (на одной высоте)
Горизонтальные позиции:

current в центре (x=0 от центра экрана).

prev слева, next справа.

CAROUSEL_SIDE_X_RATIO = 0.40 — замер по герой.jpg: центр соседа стоит в 0.36–0.41 ширины от середины экрана, поэтому шар виден ~80–85 %. При 0.45 сосед обрезан наполовину, при 0.55 уходит за край на две трети и превращается в цветное пятно.

Раскладка слотов: три — prev / current / next.

Из матрицы вынимается ТОЛЬКО центральный шар (его ячейка пустеет), а соседи — декоративные копии с той же текстурой: их оригиналы продолжают стоять в матрице на своих местах.

Слотов ±2 и дальше нет: страница = шаг CAROUSEL_SIDE_X_RATIO, поэтому после snap роли просто меняются.

Порядок эмоций: линейный по EMOTIONS, бесконечный:

next от loneliness (idx 17) → love (idx 0)

prev от love (idx 0) → loneliness (idx 17)

Поведение:

Drag управляет лентой 1:1 (палец).

Snap при отпускании: >50% ширины или ускорение.

Fling (быстрый свайп): 5 страниц за раз, каждая — видимая snap-анимация.

Заголовок и аннотация обновляются мгновенно, как только новый центр перешёл 50% пути.

5.1. Точка касания пальца
Положение: палец пользователя касается нижней трети персонажа (в районе «животика»).

Из скриншота захват.png:

Красный кружок — точка касания.

Она находится на ~35% от низа персонажа.

Значит, центр персонажа выше точки касания на ~65% от его высоты.

Формула смещения (для кода):

text
holdOffsetY = -radius * BALL_HOLD_SCALE * 0.35;
// где radius — базовый радиус в матрице, BALL_HOLD_SCALE = 2.2
Эффект: персонаж «стоит» над пальцем, его лицо видно, палец не закрывает морду.
